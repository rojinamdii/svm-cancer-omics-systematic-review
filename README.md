# SVM Models for Cancer Detection Using Omics and Omics-Adjacent Data

This repository contains data and reproducibility materials associated with the systematic review:

**Support Vector Machine Models for Cancer Detection and Related Clinical Applications Using Omics and Omics-Adjacent Data: A Systematic Review**

**Journal:** BioMed Research International  
**Status:** Accepted for publication

## Overview

This systematic review evaluates Support Vector Machine (SVM) models used in cancer-related molecular-omics and omics-adjacent applications.

The final evidence base includes:

- 75 included studies
- 60 molecular-omics studies
- 15 omics-adjacent studies
- 544 article-level SVM performance entries
- PROBAST risk-of-bias assessments for all included studies

No pooled meta-analysis was performed because of substantial clinical and methodological heterogeneity.

## Repository Contents

### `data/`

Contains the article-level supplementary dataset used in the review.

The main workbook is:

`Supplementary_Data_File_1.xlsx`

It includes:

- Eligibility decisions for 96 full-text reports
- Characteristics of the 75 included studies
- SVM model and validation details
- Reported performance metrics
- PROBAST risk-of-bias assessments
- Geographic audit variables
